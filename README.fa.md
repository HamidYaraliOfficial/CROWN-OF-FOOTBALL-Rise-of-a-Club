## معرفی
یک بازی مدیریتی فوتبال تحت وب با باشگاه‌ها و بازیکنان خیالی؛ شامل مدیریت تیم، نقل‌وانتقالات، بودجه، قرارداد، تاکتیک، استعدادیابی، مسابقه آماری و جدول لیگ.

## اجرای سریع
در ویندوز فایل `RUN-PLAY-NOW.bat` را اجرا کن. روش دستی در ریشه پروژه:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/PLAY_NOW.html` را باز کنید. نسخه مستقل بدون نصب npm اجرا می‌شود و دارای رابط فارسی، انگلیسی و چینی، ذخیره محلی و خروجی/ورود JSON است.

## تست‌های مستقل بدون وابستگی npm
```bash
node scripts/verify-standalone.cjs
node scripts/smoke-offline.cjs
```
این تست‌ها نحو کد مستقل و چند گردش کار اصلی را با DOM شبیه‌سازی‌شده بررسی می‌کنند، اما جایگزین تست در مرورگر واقعی نیستند.

## نسخه توسعه
```bash
npm install
npm run dev
```
برای اجرای وب و API: `npm run dev:full`؛ برای ساخت و تست: `npm run build` و `npm test`.

## وضعیت
فایل مستقل `PLAY_NOW.html` برای اجرای فوری آماده شده است. برنامه React/Three.js و API توسعه‌پذیرند، اما build آن‌ها نیازمند نصب وابستگی‌هاست. API در حال حاضر از adapter حافظه‌ای استفاده می‌کند؛ طرح `database/schema.sql` هنوز به مسیر پایدار Career متصل نشده است. این محدودیت‌ها در README اصلی نیز ثبت شده‌اند.
