# Changelog

## 1.0.0 — 2026-10-29

- Added a standalone browser playable entry point (`PLAY_NOW.html`) with Persian, English, and Simplified Chinese interfaces.
- Added fictional clubs, players, round-robin league fixtures, squad management, transfer offers, finances, training, scouting, facilities, tactical settings, match simulation, standings, local storage, and JSON career import/export.
- Added a React/TypeScript development frontend and Three.js match visualization.
- Added a NestJS API scaffold, career endpoints, a development in-memory adapter, and a proposed PostgreSQL schema.
- Added proprietary all-rights-reserved copyright notice for Hamid Yarali.
- Added dependency-free syntax and mocked-DOM smoke checks.
- Documented build-verification limitations caused by the authoring environment's dependency network restrictions.
