# Security Policy

This repository is a development project. Do not store credentials, tokens, private save files, or real personal data in issues or commits.

For a suspected vulnerability, contact the project owner through https://github.com/HamidYaraliOfficial. Include an impact summary and reproduction steps without publishing sensitive data. Do not test against systems you do not own or have permission to assess.

Before any public online deployment, implement authentication, authorization, per-career isolation, server-side validation, rate limiting, secure secret management, dependency review, and audit logging.
